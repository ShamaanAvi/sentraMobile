# App Store Listing Submission Draft

## App Name
SENTRA Mobile

## Subtitle
Secure mobile access to SENTRA

## Promotional Text
Access SENTRA securely from your iPhone with native file handling and external link support.

## Description
SENTRA Mobile is the official iOS access point for the SENTRA platform at https://sentra.airforce.lk.

Features:
- Secure in-app access to SENTRA internal pages
- External links open with appropriate native apps
- Upload support for camera, gallery, files, and PDFs
- Download and open files with native app integration
- Offline-aware behavior and resilient error handling

Security:
- HTTPS-only internal navigation
- Web content hardening and release-safe configuration
