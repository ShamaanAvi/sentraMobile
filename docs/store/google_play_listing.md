# Google Play Listing Submission Draft

## App Name
SENTRA Mobile

## Short Description (80 chars max)
Secure mobile access to SENTRA with native file handling and URL handoff.

## Full Description
SENTRA Mobile provides secure Android access to the SENTRA platform at https://sentra.airforce.lk through a production-grade native shell.

Key capabilities:
- Secure in-app loading for SENTRA internal URLs
- Native handling for external links (phone, mail, maps, YouTube, and more)
- File uploads using camera, gallery, and file picker flows
- File downloads with native open-file handoff
- Offline and error-aware user experience
- Android back handling and pull-to-refresh support

Security and reliability:
- HTTPS-only navigation policy for internal web content
- Mixed-content blocking and WebView security hardening
- Release-mode debugging disabled
