PRODUCT REQUIREMENTS DOCUMENT (PRD)
Project Title

    SENTRA Mobile Application

Project Overview

    The SENTRA Mobile Application is a Flutter-based mobile application for Android and iOS that serves as a native wrapper around the existing web application hosted at:

    https://sentra.airforce.lk

    The mobile application shall provide a seamless user experience by loading the existing web application inside an optimized WebView while adding native mobile capabilities, platform integrations, performance optimizations, and store-compliant user experiences.

    The goal is to reuse the existing Next.js frontend and Laravel backend infrastructure while minimizing duplication of business logic.

Business Objectives
    Primary Objectives
        Provide Android and iOS access to SENTRA.
        Reuse the existing web application.
        Reduce development cost.
        Maintain a single source of truth for business logic.
        Enable future mobile-native enhancements.
    Secondary Objectives
        Push notifications.
        Deep linking.
        Biometric authentication support.
        Offline awareness.
        Native file handling.

Existing System
    Frontend
        Next.js
    Backend
        Laravel API
    Database
        MySQL
    Infrastructure
        Docker Containers
    Production URL
        https://sentra.airforce.lk

User Roles

    The application must support all existing user roles available in the web application without modification.

    Authentication and authorization shall remain controlled by the existing Laravel backend.

Functional Requirements
    FR-001 Application Launch

        The application shall:

        Display native splash screen.
        Verify internet availability.
        Load SENTRA URL.

    FR-002 Web Application Loading

        The application shall:

        Load:

        https://sentra.airforce.lk

        Use secure HTTPS communication.
        Preserve cookies.
        Preserve session state.

    FR-003 Authentication

        The application shall:

        Support existing login mechanism.
        Support session persistence.
        Automatically restore active sessions.

    FR-004 Navigation

        The application shall:

        Support browser history.
        Support Android back button.
        Prevent accidental app exits.
        Handle external URLs.
        External URL Handling

        Examples:

        YouTube
        Google Maps
        Mail links
        Telephone links

        Must open using native applications.

    FR-005 File Upload

        The application shall support:

        Camera
        Photo gallery
        File picker
        PDF upload
        Image upload

    FR-006 File Download

        The application shall:

        Download files generated by SENTRA.
        Support PDF downloads.
        Support image downloads.
        Open files using device applications.

    FR-007 Connectivity Handling

        The application shall:

        Detect offline state.
        Show connectivity screen.
        Retry automatically.

    FR-008 Error Handling

        The application shall display:

        Network Errors
        No internet
        Server Errors
        500
        502
        503
        Maintenance Mode

        Custom maintenance page.

    FR-009 Push Notifications (Future Ready)

        Application architecture shall support:

        Firebase Cloud Messaging
        APNS

        without major refactoring.

    FR-010 Deep Linking

        Support:

        sentra://

        and

        https://sentra.airforce.lk/*

        deep links.

    FR-011 Device Orientation

        Application shall support:

        Portrait

        Optional:

        Landscape

    FR-012 Session Management

        The application shall:

        Store cookies securely.
        Restore sessions after restart.
        Handle logout correctly.

    FR-013 Security

    The application shall:

    Prevent mixed content.
    Block insecure URLs.
    Validate SSL certificates.
    Prevent WebView debugging in production.
